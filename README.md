# Problem Solving and Search in AI

Repository for the TU Wien course **Problem Solving and Search in AI**.

The assignments are separated by folder:

- `task1/PSSAI_Assignment1/`: Assignment 1 material.
- `task2/PSSAI_Assignment2/`: Assignment 2 metaheuristic solver for Topic A.

Assignment 2 uses Simulated Annealing and keeps all Topic A hard constraints,
including resource capacities.
